Instructions to install the Testing Zip:
Drop melee.zip into your PortMaster autoinstall folder and run PortMaster.
or
run via ssh: harbourmaster install "zip url from discord"

Game Information
Title: Super Smash Bros. Melee (native)
URL: https://github.com/zalo/melee/tree/portmaster (game code from https://github.com/doldecomp/melee, rendering by https://github.com/encounter/aurora)

Instructions:
Copy your own US 1.02 disc image (GALE01; .iso, .gcm, .ciso or .rvz) into ports/melee/assets/.
Launch "Super Smash Bros. Melee (native)" and answer Yes at the memory-card prompt.
The first matches stutter while shaders compile; please report FPS from the second launch on,
and attach ports/melee/log.txt to every report.

| Button | Action |
|--|--|
| D-pad | Control stick (move, menu cursor) |
| Left stick | GameCube D-pad (taunt) |
| Right stick | C-stick (smash attacks) |
| A | A (attack, confirm) |
| B | B (special, back) |
| X | Jump |
| Y | Jump |
| R1 | Z (grab) |
| L2 | L (shield) |
| R2 | R (shield) |
| Start | Start / pause |
| Start + Select | Exit to the CFW menu |

Untested so far: muOS, ArkOS, resolutions above 640x480, H700 / A133P / Snapdragon devices. Reports from those are the most useful.
