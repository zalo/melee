Super Smash Bros. Melee (native) - testing thread

Install
1. Install melee.zip through PortMaster (or unzip it into your ports folder).
2. Copy your own US 1.02 disc image (.iso, .gcm, .ciso or .rvz, GALE01) into ports/melee/assets/.
3. Launch "Super Smash Bros. Melee (native)". Answer Yes at the memory-card prompt.
The first matches stutter while shaders compile; please report FPS from the second launch on.
Please attach ports/melee/log.txt to every report.

Buttons (check each one in a VS match and in the menus)
[ ] D-pad = control stick (move, menu cursor)
[ ] Left stick = D-pad (taunt)
[ ] Right stick = C-stick (smash attacks)
[ ] A = A (attack, confirm)
[ ] B = B (special, back)
[ ] X = jump
[ ] Y = jump
[ ] R1 = Z (grab)
[ ] L2 = L (shield)
[ ] R2 = R (shield)
[ ] Start = pause / start
[ ] Start + Select = exit back to the CFW menu
[ ] No stray keyboard input in menus or name entry
